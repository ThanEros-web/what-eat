# 🍜 今天吃什么 · 🎒 去哪玩

吃什么、去哪玩都纠结？选好条件，剩下的交给它。页面顶部可以在两个工具之间切换。

**在线使用：** https://thaneros-web.github.io/what-eat/
（直接打开去哪玩：https://thaneros-web.github.io/what-eat/#play ）

## 功能

### 🍜 吃什么

- **随机选菜**：可以按分类（早餐 / 正餐 / 面食 / 快餐 / 轻食 / 夜宵）和口味（辣 / 清淡 / 热乎 / 便宜 / 吃顿好的）筛选
- **会看时间**：早上自动切到早餐，深夜自动切到夜宵
- **常吃程度**：越爱吃的菜越容易被选中（偶尔 → 本命，分五档）
- **避开最近吃过的**：最近 N 天吃过的菜先不选，可以开关
- **换一个**：不满意就换，换太多次会被吐槽，最后还会劝你回到第一个
- **自己的菜单**：可以添加、修改、删除菜品，输入菜名后会自动猜图标、分类和口味；也可以用「批量添加」一次加好几道
- **吃饭记录**：点「就吃这个」后记下来，每周给一句小结
- **撤销**：删除、恢复默认菜单、清空记录都可以撤销
- 电脑上按 **空格键** 也能抽

### 🎒 去哪玩

- **随机抽去处**：可以按分类（户外 / 城市漫游 / 文艺 / 运动 / 玩乐 / 放松）、时间（一两个小时 / 半天 / 一整天）和条件（下雨也行 / 省钱 / 晚上能去）筛选
- **出行车票**：抽中的结果做成一张车票，写着分类、时长和特点
- **随机小任务**：可以附带一个出门小任务，比如「拍一张今天天空的照片」，增加一点乐趣
- **会看时间**：晚上自动筛「晚上能去」的，周末默认按一整天来安排
- 和吃什么一样支持：喜欢程度加权、避开最近去过的、换一个、自己的清单（单个 / 批量添加）、出行记录、撤销

## 在手机上使用

用浏览器打开上面的网址即可，安卓和 iPhone 都支持。

**iPhone 用户建议：** 在 Safari 里点「分享 → 添加到主屏幕」，以后从主屏幕图标打开，使用体验更像 App。
> Safari 会自动清除 7 天没访问过的网站数据，添加到主屏幕后就不会被清，菜单和记录可以一直保存。

**系统要求：** iOS 16.4 及以上，或较新版本的 Chrome / Edge / Firefox / Safari。

## 数据保存在哪里

菜单、去处清单和记录都只保存在**你自己的浏览器里**（localStorage），不会上传到任何服务器。

- 换手机、换浏览器，或者清除浏览器数据后，记录不会跟过去
- 不同人用同一个网址，各自的数据互不影响

## 技术说明

- React + TypeScript + Vite
- UI 组件：[shadcn/ui](https://ui.shadcn.com/)（基于 Radix UI + Tailwind CSS v4），图标用 [lucide](https://lucide.dev/)
- 打包成单个 `index.html`（用 vite-plugin-singlefile 把脚本和样式都内联进去），不依赖外部文件，下载下来也能离线打开（仅限电脑；iPhone 不能直接打开本地 HTML 文件）

本仓库只放了打包后的网页文件，源码在本地的 `what-to-eat-ui` 项目中。
